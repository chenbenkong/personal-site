### 环境踩坑（重要，避免重蹈）
- **GitHub MCP 连接器无建库权限**：`mcp__github__create_repository` 报 403（integration）。解决：本地装 `gh` CLI（winget 安装到 `C:\Program Files\GitHub CLI\gh.exe`，需 `export PATH="$PATH:/c/Program Files/GitHub CLI"`），`gh auth login --web` 设备流授权，再 `gh repo create` + git push。
- **安全删除策略会延迟执行**：`rm -rf` 大目录被 SAFE_DELETE 拦截并升级批准，批准后可能在后续命令才真正执行，把我刚 cp 回的文件又删掉（包括 .workbuddy 记忆目录）。
  - 对策：克隆模板到仓库内 `tmpl/`，改完用"按文件名精准删旧文件 + cp tmpl 内容"替换；`tmpl/`、`v4-tmp/` 等写入 .gitignore；避免批量 rm。
  - 注意：手写/追加的 .gitignore 规则和 deploy.yml，若在"延迟 rm → 重新 cp tmpl"之间，会被模板原版覆盖，需重新写入并验证。
